# 《星火守衛：符文林地》（Ember Warden: Runewood）

工作室編號 `#01` 第一款完整獨立製作的奇幻俯視角生存射擊遊戲。

## 快速啟動
- **方式一（推薦）**：於此資料夾開啟終端機執行本地伺服器，再用瀏覽器開啟 `http://127.0.0.1:8765/`：
  ```powershell
  python -m http.server 8765 --bind 127.0.0.1
  ```
- **方式二**：直接以 Chrome / Edge 等現代瀏覽器雙擊開啟 [index.html](index.html)。

## 操作方式
- **移動**：`WASD` 或 `方向鍵`
- **瞄準與攻擊**：滑鼠游標瞄準（預設自動施法）；**滑鼠左鍵**施放「星火連爆」（可於暫停選單開關自動施法）
- **秘法瞬步（無敵閃避）**：`Space` / `Shift` / `滑鼠右鍵`
- **升級三選一**：點擊祝福卡片或按 `1` / `2` / `3`
- **系統功能**：`P` / `Esc` 暫停（內含已覺醒符文祝福總覽）、`M` 靜音切換

## 資料夾結構
- `index.html` / `style.css` / `game.js` — 遊戲主程式與 carved-stone 介面
- `assets/` — 14 張實體去背手繪奇幻 2D 精靈與林地競技場背景
- `GAME_SPEC.md` — 遊戲設計規格書（含 v1.1 體驗強化規格）
- `ART_SPEC.md` — 美術風格、5 色核心色盤與資產規範
